# K-Buddy 🇰🇷 | 외국인 여행자를 위한 다국어 한국 생활 도우미

> **Frontend Web Application · React · TypeScript · Vite**  
> 한국 방문자가 여행과 일상에서 마주하는 언어·이동·음식 정보의 장벽을 줄이기 위한 모바일 중심 웹앱입니다.

## 1. 프로젝트 개요

K-Buddy는 한국을 방문한 외국인 여행자를 위해 **번역, 대중교통 길찾기, 음식·알레르기 정보, 생활 안전 안내**를 한 곳에 모은 서비스입니다. 여러 정보를 오가며 찾아야 하는 사용자의 불편을 줄이는 것을 목표로 했습니다.

- **프로젝트 유형:** 웹 애플리케이션 / 6인 팀 프로젝트
- **주요 사용자:** 한국 여행 및 단기 체류 중인 외국인
- **개발 행사:** 멘사 해커톤 (2026년 10월 31일)
- **개발 기간:** 2026.10.31 (1일, 해커톤 당일)
- **나의 담당 역할:** 개발 총괄
- **형태:** 반응형 웹 / 모바일 사용 환경 우선
- **데모:** 공개 가능한 실제 서비스 주소를 확인한 후 기재 (현재 소스에는 배포 설정 미포함)

## 2. 주요 기능

| 기능 | 설명 | 참고 |
| --- | --- | --- |
| 다국어 안내·표현 | 상황별 한국어 표현, 여행·생활 가이드 | 정적 데이터 및 UI |
| AI 번역·상황별 지원 | 입력 상황에 따른 AI 기반 응답 | Google Gemini, **사용자 본인 API 키 필요** |
| 길찾기·지도 | 이동 경로 및 지도 연결 | Kakao Maps·ODsay 키 설정에 따라 제공 |
| 음식·알레르기 정보 | 음식 선택에 도움이 되는 성분/주의 정보 | 의료적 판단을 대체하지 않음 |
| 안전·생활 정보 | 생활 안내 및 URL 안전성 관련 기능 | 일부 기능에 외부 API 키 필요 |
| QR·음성 리소스 | 상점 링크 공유, 사전 제작 음성 안내 | 미디어 재배포 권한 확인 필요 |

> API 키가 없거나 외부 서비스가 응답하지 않는 경우 일부 기능은 사용이 제한되거나 대체 데이터로 동작합니다. 전체 동작 보장 여부는 각 환경에서 테스트해야 합니다.

## 3. 기술 스택

| 구분 | 기술 |
| --- | --- |
| Language | TypeScript |

| Styling / UI | Tailwind CSS 4, shadcn/ui 관련 컴포넌트, Lucide |

## 5. 로컬 실행

**요구 환경:** Node.js 22 이상 및 npm (일부 최신 의존성은 더 높은 세부 버전을 요구할 수 있음)

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_REPOSITORY_DIRECTORY>
npm ci
```

`.env.example`을 `.env.local`로 복사하고 사용하는 외부 서비스의 키를 설정합니다. 필요하지 않은 키는 비워둘 수 있습니다.

```dotenv
VITE_KAKAO_JS_KEY=
VITE_ODSAY_KEY=
VITE_SAFE_BROWSING_KEY=
```

```bash
npm run dev
```

Gemini 기능은 사용자가 **앱 화면에서 직접 자신의 API 키를 입력하는 방식(BYOK)** 입니다. 개발자 키를 포함하지 않습니다. 현재 구현에서는 해당 키가 브라우저의 `localStorage`에 보관됩니다. 공유 PC에서는 사용 후 지우고, 공개 배포 시에는 서버 기반 인증·프록시로 개선하는 것을 권장합니다.

> **중요:** `VITE_`로 시작하는 값은 빌드된 JavaScript에 공개될 수 있습니다. 비밀로 유지해야 하는 키를 넣지 마세요. 공개 브라우저 키를 사용한다면 제공업체의 허용 도메인 및 사용량 제한을 설정해야 합니다. Safe Browsing 키는 서버 프록시로 이전하는 것이 바람직합니다.

```bash

```

검증 명령의 실제 성공 여부는 개발 환경에서 별도 확인해야 합니다. 이 자료는 외부 API 및 키 없이 모든 기능이 정상 동작한다고 보증하지 않습니다.

## 9. 공개·보안·라이선스 안내

- `.env.local`, 실제 API 키, 서버 인증 파일은 공개 저장소에 커밋하지 않습니다.
- **Firebase Hosting 설정과 기존 배포 프로젝트 연결 정보는 이 버전에서 제거했습니다.** 이 소스 자체에는 자동 배포 설정이 없습니다.
- 이미지·아이콘·QR 자료·`public/voices/` 등의 콘텐츠는 코드와 별도로 재배포 권한을 확인해야 합니다.
- 본 코드의 라이선스는 지정되지 않았습니다. 팀 공동 저작물 및 외부 자료의 공개·사용 허가를 확인한 후 라이선스를 결정하세요.
- 음식 알레르기, 이동 경로, 긴급 안전 관련 안내는 정확성을 항상 보증할 수 없으므로 공식 기관이나 현장 담당자에게 확인해야 합니다.
